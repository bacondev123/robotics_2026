## 📜 Part 2: Quick Reference / Cheatsheet 

### 1. Raycast & Dash Fundamentals
- **Raycast Basics**: `workspace:Raycast(Origin, Direction, Params)`
- **Dash / Move**: Assign an `Attachment` inside the HumanoidRootPart and pair it with a `LinearVelocity` modifier.

### 2. Tweening Service Usage 

**Step-by-step Structure:**
```lua
local TweenService = game:GetService("TweenService")

-- 1. เลือกของที่จะเปลี่ยน
local objectToAnimate = workspace.CurrentCamera

-- 2. ตั้งค่าระยะเวลาและสไตล์ (TweenInfo)
local tweenInfo = TweenInfo.new(
    0.5, -- ใช้เวลา 0.5 วินาที
    Enum.EasingStyle.Sine, -- สไตล์การขยับ (นุ่มนวล)
    Enum.EasingDirection.Out -- ค่อยๆ ช้าลงตอนจบ
)

-- 3. กำหนดค่าเป้าหมาย (Goal) ให้อยู่ในปีกกาเสมอ
local goal = { FieldOfView = 90 }

-- 4. สร้างและ Play!
local tween = TweenService:Create(objectToAnimate, tweenInfo, goal)
tween:Play()

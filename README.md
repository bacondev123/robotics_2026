# Robotics

Personal repository for robotics club code, sensor tests, and motor control scripts.

### Boards
- POP32
- ATX2
- PTBOT Atom VX

### Requirements
- Arduino IDE 2.x or VS Code with Arduino extension
- INEX POP32 / ATX2 hardware libraries
- PTBOT Atom VX libraries (Package: https://github.com/pt-robotics/esp32/raw/main/package_ptbot_index.json )
